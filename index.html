connect the bonds

a hashi-like puzzle with atoms. every atom wants its full valence — H wants 1, O wants 2, N wants 3, C wants 4.

1 · hydrogen gas
tap an atom, then tap another in the same row or column.
hint: …
how to play (30 sec)

1. Tap / drag from one atom to another in the same row or column with nothing in between.
2. Each tap adds one bond: 1 line → 2 lines → 3 lines → back to 0.
3. Bonds can't cross and can't use more than an atom wants.
4. Win when every atom is happy and everything is connected into one molecule.
5. Tip: click a bond's middle to remove one. u=undo, r=clear.

In class N was written as 2 sometimes — here we use the real thing: N wants 3. H 1 · O 2 · N 3 · C 4.
